# 打戏/动作视频详细规则与示例

## 1. 五大致命问题与修复

| 问题 | 修复方案 (提示词) |
|------|------------------|
| 没有速度感 | `high-speed camera tracking, motion blur, fast-paced editing` |
| 没有冲击感 | `impact frames, shockwave, low angle shot, dynamic lighting` |
| 站得太近 | `3-5 meters combat distance, clear spacing` |
| 瞬移 | `continuous action, grounded stance, clear trajectory` |
| 人景隔开 | `tight lighting interaction, environment reflection on character` |

## 2. 表情对照表

| 状态 | 中文描述 | 英文提示词 |
|------|---------|------------|
| 攻击 | 咬牙切齿/怒吼 | `gritting teeth, fierce roar` |
| 防御 | 痛苦/吃力 | `strained expression, grimacing` |
| 碾压 | 微笑/从容 | `slight smirk, relaxed` |
| 受击 | 痛苦/惊讶 | `shocked, wincing` |
| 胜利 | 喘息/得意 | `catching breath, triumphant` |

## 3. 运镜三要素详解

1. **高速运镜跟随 (High-Speed Camera Tracking)** ← 最重要！
   - 镜头像"摄像机扛在手上追着跑"一样，紧紧跟着主角/武器快速移动
   - 举例：3-4s 横斩战舰 → 镜头跟着女主高速飞过，一剑斩下，镜头同步移动，观众感觉自己在跟着她一起飞
   - 举例：4-5s 穿梭连斩 → 镜头追着女主在战舰群中来回穿梭，连续斩击，镜头快速跟随她的移动轨迹
   - **为什么排第一？** 速度感是打戏最核心的东西。没有高速跟随，画面就是"软绵绵"的，观众感觉不到打斗的力度和节奏。有了高速跟随，哪怕动作本身一般，观众也会觉得"好帅好快"
   - 对比固定镜头：固定镜头是旁观者视角，高速跟随是身临其境跟着一起打

2. **环绕运镜 (Orbital Camera Movement)**
   - 镜头围绕角色/武器旋转
   - 适用场景：对峙、蓄力、对拼瞬间
   - **叶老师原话**："不是像《青蛇》《白蛇》那种"
   - 意思是：打戏里的环绕要干脆利落，快速有力度，不要像仙侠剧那种慢悠悠、拖泥带水的旋转
   - 类似《黑客帝国》子弹时间的快速环绕效果

3. **快速切换 (Rapid Shot Cuts)**
   - 不同景别快速切换（广角↔特写↔中景）
   - 适用场景：连击、多角色混战
   - 增强节奏感和视觉冲击力
   - 叶老师原话："15秒的镜头，你不可能全部都用一个镜头"

## 4. 镜头规则细节

- **15 秒定律**：15 秒内必须切至少 3 个镜头（正反打除外）
- **固定镜头优先**：前 3 个固定镜头不要运镜
- **切镜优于运镜**：对话场景用"近景↔特写"切换代替旋转运镜

## 5. 7 项自检清单 (Checklist)

- [x] 高速运动标签
- [x] 表情变化描述
- [x] 至少 3 个切镜
- [x] 角色融入场景
- [x] 速度感/冲击感关键词
- [x] 避免推镜头/一镜到底
- [x] 站位距离合理

## 6. AI 模型特性

- **即梦 (Jimeng)**：容易偷懒生成慢镜头，出现"拉稀感"需更换
- **注意**：原始培训记录中老师口误将「即梦」说成「吉梦」，实际产品名称为「即梦（Jimeng）」
- **Seedance 2.0**：打戏效果佳，推荐首选
- **可灵 1.6 Pro**：场景融合好，适合大场面
