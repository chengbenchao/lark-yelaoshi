# 🚀 打戏速度感提示词词库

> 基于叶老师培训提炼 + 实战验证
> 核心原则：打戏运镜就一个字——**快！**

---

## 1. 必加基础速度词

> 提示词里必须有至少一个！

| 英文 | 中文含义 | 使用场景 |
|------|---------|---------|
| `fast` | 快速 | 通用，最基础 |
| `quick` | 迅速 | 强调反应快 |
| `rapid` | 急促 | 强调频率高 |
| `swift` | 敏捷 | 强调动作利落 |
| `dynamic` | 动态 | 强调画面动感 |
| `agile` | 灵活 | 强调身法灵活 |
| `high speed` | 高速 | 强调绝对速度 |
| `fast-paced` | 快节奏 | 强调整体节奏 |

---

## 2. 强化动感词

> 配合基础词使用，增强画面动感

| 英文短语 | 说明 |
|---------|------|
| `fast movement` | 快速移动 |
| `fast motion` | 快速运动 |
| `quick attacks` | 快速攻击 |
| `rapid punches` | 快速出拳 |
| `fast kicks` | 快速踢击 |
| `fluid motion` | 流畅运动 |
| `smooth and fast` | 顺滑且快速 |

---

## 3. 镜头 & 节奏词

> 控制 AI 视频的运镜速度和剪辑节奏

| 英文短语 | 说明 |
|---------|------|
| `fast cutting` | 快速剪辑 |
| `quick cuts` | 快速切换镜头 |
| `dynamic camera` | 动态摄像机运动 |
| `fast-paced action` | 快节奏动作 |
| `intense speed` | 强烈速度感 |

---

## 4. 万能组合公式

```
动作词 + fast/rapid/swift + fluid/dynamic
```

### ✅ 组合示例

| 组合 | 效果 |
|------|------|
| `swift strikes, fluid motion` | 利落攻击，流畅身法 |
| `rapid movement, dynamic camera` | 快速位移，动态镜头 |
| `fast-paced combat, quick cuts` | 快节奏战斗，快速切镜 |
| `high speed chase, agile dodging` | 高速追逐，灵活闪避 |

---

## 5. 叶老师原话对应

> "高速运镜跟随，为什么高速运镜跟随是第一个？打戏最重要的一个点是什么？要有速度感，从重力看起来要帅。"

| 叶老师要求 | 对应提示词 |
|-----------|-----------|
| 速度感 | `fast, high speed, rapid` |
| 看起来帅 | `dynamic, swift, fluid motion` |
| 不要软绵绵 | `intense speed, fast-paced action` |
| 不要慢镜头 | `no slow motion, no drag` |

---

## 6. 避坑提醒

| ❌ 避免使用的词 | 原因 |
|---------------|------|
| `slow motion` | 会产生慢动作，打戏大忌 |
| `gentle` | 太柔和，没力度 |
| `graceful` | 偏优雅，不够凌厉 |
| `calm` | 太平静，没紧张感 |

**正确做法**：如果 AI 生成慢镜头，加 `no slow motion, fast-paced only` 强制纠正。
